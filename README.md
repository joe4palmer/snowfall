# Snowfall

A Claude Code mod that puts a snowy night behind your conversation: a moon, twinkling stars, a decorated tree and a lit cabin. Snow piles up as your context window fills, and a little sign shows the percentage. After `/compact` (or an automatic compaction) the pile melts back down to the new level. `/clear` clears the ground. Backdrops are drawn by the Claude desktop and mobile apps; the terminal shows nothing.

## Install

At the prompt of a terminal session:

```
/plugin install snowfall --marketplace joe4palmer/snowfall
```

Answer `y` to add the marketplace, then pick a scope.

From a shell:

```bash
claude plugin install snowfall --marketplace joe4palmer/snowfall
```

In the desktop app, where `/plugin` does not run: click + next to the prompt box, then Plugins, Add marketplace with `joe4palmer/snowfall`, then Add plugin.
